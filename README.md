# Data Analysis Portfolio: IBM Data Science Coursework

**Pierre Foy, MBA, PMP**

This repository collects selected projects from the **IBM Data Science Professional Certificate** program on Coursera. I completed 8 of the program's courses between December 2023 and May 2024. My professional background is more than 20 years in pharmaceutical clinical research, project management and quality review. These projects show how I apply a structured, evidence-based approach to data: define the question, check the data, analyze it, and state what the results do and do not support.

> These are course projects built on IBM-provided datasets and lab templates. They show coursework-level skills, not production systems. Project notebooks are based on IBM lab templates and are not posted here; they are available on request.

## How I approach analytical work

**Clarify → Decompose → Verify → Compare → Conclude → Document uncertainty**

- A plausible result is not the same as a supported one.
- Keep evidence separate from assumptions.
- Say what a model or chart does *not* show.
